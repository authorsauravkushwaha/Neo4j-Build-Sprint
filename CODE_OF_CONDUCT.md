# Code of conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct. The full
text is published at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and is
included here by reference rather than copied, so the canonical version is never stale.

In short, as a participant you agree to:

- Be respectful of differing viewpoints, experience levels and career paths. This project
  exists for people who are starting out and for people who are experts; neither is the
  default.
- Give and accept constructive feedback about the work, not the person.
- Refrain from harassment, personal attacks, sexualised attention, and publishing others'
  private information.
- Respect the honesty rules the repository enforces: do not add invented users, testimonials,
  ratings, outcomes or measurements, and do not describe an unverified thing as verified.

Enforcement contact: once the repository is published, report concerns privately to the
maintainers through the repository's security advisory channel (Security → Advisories), which
keeps the report confidential until it is resolved. Until a repository exists, this file is a
statement of intent for contributors, not a live process.
